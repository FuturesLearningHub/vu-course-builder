# Vanderbilt Learning Series course builder

Each course in the series is a single-page interactive site: one `index.html`
deck, one CSS file, one JS file, no frameworks, self-hosted fonts, published
to GitHub Pages. Every course ships as **three editions** from one source:

1. **Classroom** (`index.html`) - projected in a room, QR welcome slide, group activities.
2. **Self-paced web** (`web/index.html`) - GENERATED by `tools/build-web.py`, never hand-edited. Same course minus the welcome slide and everything tagged `data-classroom`.
3. **Facilitator** (`facilitator/index.html` + printable `facilitator/guide.html`) - GENERATED by `tools/build-facilitator.py` from `facilitator/notes.json`, never hand-edited.

The catalog lives in the `me5231979/Course_Library` repo and every course gets
a card there. Live sites: `https://me5231979.github.io/<Repo_Name>/`.

## Starting a new course

Do not scaffold from scratch. Clone the newest sibling course repo as your
template - it already carries the engine, fonts, brand CSS, and both
generators. As of writing the best template is `me5231979/emotional-intelligence`
(90/60 course) or `me5231979/AI_Classroom` (60/30 beginner course).

1. Clone the template repo into the new course repo's directory; keep `assets/fonts/`, `assets/js/qrcode.min.js`, the CSS engine blocks, and `tools/` intact.
2. Replace the copy slide by slide. Course shape: Welcome/QR (classroom only) -> Hero (objectives + skills row) -> Agenda -> 4 to 6 teaching sections, each with an interactive moment -> Recap quiz -> Capstone commitment card -> Closing (footer lives inside the closing slide).
3. Rewrite the trainer configs, recap `QUESTIONS`, and capstone maps in `assets/js/main.js`.
4. Rewrite `facilitator/notes.json` for the new sections (see the runbook reference).
5. Regenerate: `python3 tools/build-web.py` then `python3 tools/build-facilitator.py`.
6. Screenshot every slide for the printable guide (see workflow below).
7. Test with Playwright, publish, then add the library card and syllabus.

## Design system in one paragraph

Vanderbilt FLH brand: near-black `#1C1C1C` background, white text, flat gold
`#CFAE70` accents (CSS vars `--vu-black`, `--vu-white`, `--vu-gold-flat`).
Headlines are Libre Caslon Display with exactly **one italic word** per
headline (`<em>` inside the `.h2`). Body is Inter; eyebrows and labels are
Antonio, uppercase, letter-spaced, gold. Motion stays at or under 400ms.
Real VU lockups only (authorized use). Full tokens and component classes:
`references/brand.md`.

## Navigation: horizontal deck

Courses advance **left to right** like a slide deck: the `.deck` is a
horizontal scroll-snap row of `100vw` slides, each slide scrolls vertically
inside itself when needed. A bottom bar shows section title, dots, count, and
square prev/next buttons; a "scroll for more" pill appears when a slide
overflows. Aim to fit each slide's content on one screen; overflow is
acceptable only with the hint visible. The top nav gets a solid black
background on every slide. Mechanics and exact CSS/JS contracts:
`references/deck.md`.

## Copy rules (do not regress)

- **Zero em or en dashes anywhere** - HTML, JS strings, JSON, worksheets. Rewrite around them; check with a grep before shipping.
- Human-sounding, warm, direct. Avoid negative parallelisms ("not X, but Y"), rule-of-three stacks, and arrow chains. Read it aloud in your head; if it sounds like marketing filler, cut it.
- Match register to audience: AI Basics assumes the learner has never opened an AI tool (no jargon at all - "it learned from examples", never "model" or "training data"). Other courses can assume a working professional.
- Every teaching section needs a play moment: a trainer, a sorter, a builder, or an inline check. Simple is not passive.
- Claims about efficiency or impact carry a cited, linked source.
- All links open in a new tab (the engine adds `target="_blank"` to non-hash links; keep that pass).
- The AI courses share one traffic light and it must never be contradicted: green = public or generic, yellow = internal, approved VU tools only, red = private information about people, never.

## Learning architecture

Every course is built on Bloom's-verb objectives, Kirkpatrick L1/L2/L3
evaluation (fist-to-five, scored recap, capstone commitment + 7-day pulse),
and an ATD-style facilitator runbook with Say / Do / Ask / Debrief /
Transition blocks per section and two timed paths (Full and Core) whose
per-section minutes **must sum exactly** to the advertised lengths.
Standard lengths: Full 90 / Core 60 (beginner courses run Full 60 / Core 30).
Schema, timing rules, and the facilitator briefing page ("Before the room
fills") are in `references/facilitator.md`.

## Generated editions

`tools/build-web.py` strips `data-classroom` elements, converts "As a group"
prompts to solo variants, retitles to ": Self-Paced", repaths assets, and
asserts no group language survives. `tools/build-facilitator.py` injects a
sticky script rail per slide (with a Hide toggle), builds the numbered
prep-page, and writes the printable `guide.html` with a slide image beside
each section's notes. **Regenerate both after any `index.html` change**, and
re-shoot slide images after any visual change. Details and the screenshot
workflow: `references/facilitator.md`.

## Testing before publish

Serve the repo locally (`python3 -m http.server`) and run Playwright
(Chromium at `/opt/pw-browsers/`, `--no-sandbox`) to verify: every trainer
round-trips, every slide either fits (overflow 0) or shows the scroll hint,
navigation dots and prev/next work, the facilitator Hide toggle works, and
the console is clean (ignore TUNNEL/net:: noise). Also grep for em dashes
and for `data-classroom` leaks in `web/index.html`.

## Publishing

```
git push -u origin main
git branch -f gh-pages main && git push -f origin gh-pages
```

Course_Library republishes automatically from a push to its `main` (Pages
workflow). Always `git pull` Course_Library before editing it; other sessions
work in it too.

## Library integration

Every course gets: a card in `Course_Library/index.html` with the three
edition buttons, a visible length badge (`Classroom X min · Self-paced ~Y min`),
3 to 5 skill pills including at least one VU core competency, `data-topics`
for the filter bar (all / ai / communication / leadership), a "Part of the
Manager Voyage program" tag when it is a manager course, and a generated
syllabus page. Card markup, pill classes, the seven core competencies, and
the syllabus tool: `references/library.md`.
